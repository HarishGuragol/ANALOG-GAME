# ANALOG: Learning Path

We learn by building **Mission 1 (Ghost Record)** piece by piece.

## Lesson loop
1. **Learn:** one concept explained simply.
2. **Build:** you do it in Unity or Blender, guided click by click.
3. **Code:** write C# together, every line explained.
4. **Check:** press Play, report what happens, fix it.
5. **Commit:** save progress to Git.

## Lesson 0: Blender basics
- **Orbit:** middle mouse drag (or two-finger drag on trackpad)
- **Pan:** `Shift` + middle mouse (or `Shift` + two-finger drag)
- **Zoom:** scroll or pinch
- Select the cube; `G` move, `R` rotate, `S` scale; `Esc` cancels
- Trackpad tip: Edit → Preferences → Input → **Emulate 3 Button Mouse**
