# ANALOG: Assets and References Research

## Decision
Meridian is a **fictional city built from scratch** in Blender, inspired by real places. Free CC0 textures are allowed. Kenney blocks are used only as temporary greybox pieces.

## Real-world city data (not used)
- **Google Photorealistic 3D Tiles + Cesium for Unity:** streams real cities into Unity. Merged scanned mesh; can't make interactive or restyle; needs API key, has usage costs and terms.
- **OpenStreetMap buildings (Cesium OSM):** simple blocks from real map footprints.
- **Why not:** built for maps and simulations, not interactive story levels.

## Asset sources
| Source | Cost | Use |
|---|---|---|
| Kenney.nl | Free (CC0) | Greybox modular blocks |
| Unity Asset Store free kits | Free | Starter modular pieces, reference |
| itch.io | Free / pay-what-you-want | Sci-fi pieces, shaders to study |
| Sketchfab / CGTrader | Some free | Reference models |
| Synty POLYGON City | Paid | Not planned |
| Poly Haven | Free (CC0) | Textures, HDRI skies |
| ambientCG | Free (CC0) | PBR textures (concrete, rust, asphalt) |

Note: most full cyberpunk city packs are paid and neon-heavy, which doesn't fit our look.
